# MacroSnap 🥗
An AI-powered nutrition tracker built with Streamlit, Google Gemini, and Twilio WhatsApp integration.

## Features
- Meal photo analysis and macro/calorie estimation via Google Gemini.
- Conversational chat interface for nutritional queries.
- Daily summary delivery to WhatsApp via Twilio.
